# 🛡️ Fundamentos de Ciberseguridad

**Curso profesional basado en NIST CSF 2.0 y tendencias 2026**

---

## 📋 Descripción del Curso

Curso práctico de ciberseguridad con enfoque en:
- Marco NIST CSF 2.0
- Gestión de identidad y acceso
- Arquitectura Zero Trust
- Inteligencia artificial en seguridad
- Criptografía post-cuántica
- Respuesta a incidentes

## 🚀 Inicio Rápido

```bash
# Clonar el curso
git clone https://github.com/statick88/cybersecurity-fundamentals.git
cd cybersecurity-fundamentos

# Ver estructura
tree -L 2
```
