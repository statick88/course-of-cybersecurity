## 1. Bienvenida

Bienvenido al curso **Fundamentos de Ciberseguridad (ABC-CYB-101)** de Abacom. Este manual es tu guía de referencia durante todo el curso. Aquí encontrarás la estructura de contenidos, la metodología de trabajo, los recursos que necesitas y las reglas de evaluación.

> **Nota:** En la versión 3.0 se actualiza la estructura a 5 módulos / 18 subtemas, 43 horas totales, 5 laboratorios integradores y contenidos transversales (IA Security, PQC, Gestión de Vulnerabilidades).

---

## 2. Objetivo general del curso

Al finalizar el curso, serás capaz de:

- Aplicar los conceptos fundamentales de ciberseguridad en contextos organizacionales.
- Diseñar controles de seguridad básicos alineados con marcos internacionales (NIST CSF 2.0, ISO 31000).
- Analizar riesgos de seguridad y proponer mitigaciones utilizando metodologías estructuradas (NIST SP 800-30).
- Evaluar vulnerabilidades y calcular su severidad utilizando CVSS v3.1.
- Desarrollar un plan de seguridad básico para una organización ficticia.
- Integrar conocimientos de ciberseguridad moderna: IA Security, Post-Quantum Cryptography (PQC) y gestión de vulnerabilidades.

## 4. Metodología de aprendizaje

### 4.1 Formato de sesión

Cada sesión sigue una estructura **teórico-práctica**:

1. **Teoría (1 h):** Exposición del concepto, estándar o técnica.
2. **Práctica (1 h):** Ejercicio guiado, laboratorio o análisis de caso.
3. **Reflexión (15 min):** Discusión grupal sobre aplicaciones en contexto real.

### 4.2 Entorno de laboratorio

- **Metasploitable 3 / DVWA:** Para prácticas de escaneo y análisis de vulnerabilidades.
- **Wireshark / Zeek:** Para análisis de tráfico de red.
- **OpenSSL / GnuPG:** Para prácticas de criptografía.
- **Nessus Essentials / OpenVAS:** Para escaneo de vulnerabilidades.
- **SIEM de prueba:** Provisto por Abacom para análisis de logs.

## 6. Reglas de evaluación

### 6.1 Escala de calificación

| Calificación | Nivel de Competencia | Descripción |
|--------------|----------------------|-------------|
| 90 – 100 | **Sobresaliente** | Domina todos los OA, aplica conceptos en contextos nuevos, propone mejoras. |
| 75 – 89 | **Satisfactorio** | Domina los OA clave, los aplica en contextos conocidos sin errores significativos. |
| 60 – 74 | **Mínimo Aprobatorio** | Domina parcialmente los OA; requiere refuerzo en algunos conceptos. |
| < 60 | **Insatisfactorio** | No alcanza el estándar mínimo; requiere repetición de contenidos. |

**Nota mínima de aprobación:** 70 / 100.

### 6.2 Política de asistencia

- Asistencia mínima requerida: **80 %** de las sesiones sincrónicas.
- El estudiante que no cumpla con el 80 % de asistencia deberá rendir un examen de recuperación.

### 6.3 Política de entrega de trabajos

- Las entregas se realizan a través del **LMS de Abacom** en la fecha indicada.
- Se aplicará un **descuento del 10 %** por día de retraso.
- Después de 3 días de retraso, el trabajo no será aceptado.

### 6.4 Política de reevaluación

| Instrumento | Política de reevaluación |
|-------------|--------------------------|
| **Quizzes por módulo** | Reevaluación antes del examen final. |
| **Laboratorios integradores** | Re-entrega dentro de las 48 h posteriores a la retroalimentación. |
| **Proyecto integrador** | No hay reevaluación directa; tutoría disponible antes de la entrega final. |
| **Examen final** | Un solo examen de recuperación por estudiante. |

## 10. Glosario básico

| Término | Definición |
|---------|------------|
| **Tríada CIA** | Confidencialidad, Integridad y Disponibilidad: los tres pilares de la seguridad de la información. |
| **NIST CSF 2.0** | Marco de Ciberseguridad del NIST que organiza la seguridad en 6 funciones: Gobernar, Identificar, Proteger, Detectar, Responder, Recuperar. |
| **ISO 31000** | Estándar internacional para la gestión de riesgos. |
| **NIST SP 800-30** | Guía del NIST para la evaluación de riesgos de sistemas de información. |
| **CVSS v3.1** | Sistema de puntuación de vulnerabilidades (Common Vulnerability Scoring System). |
| **IAM** | Gestión de Identidades y Accesos (Identity and Access Management). |
| **MFA** | Autenticación Multifactor (Multi-Factor Authentication). |
| **IDS/IPS** | Sistema de Detección / Prevención de Intrusiones. |
| **SOC** | Centro de Operaciones de Seguridad (Security Operations Center). |
| **SIEM** | Gestión de Información y Eventos de Seguridad (Security Information and Event Management). |
| **BCP/DRP** | Plan de Continuidad de Negocio / Plan de Recuperación de Desastres. |
| **Malware** | Software malicioso diseñado para dañar, infiltrar o explotar sistemas. |
| **Criptografía simétrica** | Cifrado con una sola clave compartida entre emisor y receptor. |
| **Criptografía asimétrica** | Cifrado con par de claves: pública (para cifrar) y privada (para descifrar). |
| **Hash** | Función criptográfica que produce una huella digital irreversible de un mensaje. |
| **IA Security** | Seguridad de la Inteligencia Artificial: protección de modelos, datos y pipelines de IA/ML. |
| **PQC (Post-Quantum Cryptography)** | Criptografía post-cuántica: algoritmos resistentes a ataques de computadoras cuánticas. |
| **Gestión de Vulnerabilidades** | Proceso continuo de identificación, evaluación, remediación y reporte de vulnerabilidades. |
